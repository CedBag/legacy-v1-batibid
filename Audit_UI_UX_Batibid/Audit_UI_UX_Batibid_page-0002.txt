1.1 Navigation — ce qui rend le site difficile à parcourir
La navigation est le chemin que l'utilisateur emprunte pour trouver ce qu'il cherche. Ici, plusieurs obstacles rendent ce
parcours confus.
O Les liens du menu ouvrent un nouvel onglet sans prévenir
Cliquer sur "Propriétaire/Locataire" ou "Mise en location" dans le menu provoque l'ouverture
automatique d'un second onglet vers l'application. L'utilisateur se retrouve projeté hors du site sans
l'avoir décidé. Sur mobile, gérer plusieurs onglets est peu intuitif et souvent source d'abandon.
—+ Supprimer le comportement d'ouverture forcée en nouvel onglet. Ou afficher une page de transition
expliquant clairement le passage vers l'application.
